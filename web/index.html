WasmNUX — RV32IMA core in the browser

Assembles two guest programs, runs each interpreted and through the region JIT, and reports throughput, engine counters and whether the two agree. Cross-origin isolated via COOP/COEP — set as headers by the dev server, added by a service worker on static hosts such as GitHub Pages — so SharedArrayBuffer and Wasm atomics exist (ADR-0004, ADR-0010). See web/main.ts and Spike A.
